# 虚拟工程师平台使用说明

## 悬浮实验助手（2026-09-22新增）

学生与教师页面右下角的 μ 按钮打开实验助手。点击常见问题，或输入不超过600字的操作问题后发送；Enter发送、Shift+Enter换行，Escape关闭并返回入口焦点。

基础指引无需登录，覆盖加入课堂、恢复访问、实验准备、提交、等待、审核、任务和统计。开启“智能匹配”后，登录用户未被规则匹配的问题将发送至已配置的模型，由模型选择操作类别；回复始终来自平台操作说明。模型不可用时返回基础指引并明确提示。助手不能代替诊疗提交、教师发布或评分，也不会查询个人诊疗稿。对话仅保存在当前页面内存，刷新会清空；不要输入密码、恢复码、身份信息或密钥。

接口：`POST /api/assistant`，输入 `{ "message": "如何加入课堂？", "smart": false }`；输出 `title`、`answer`、`href`、`action`、`intent`、`mode`。`mode`区分`guide`（规则匹配）、`smart`（模型匹配）、`fallback`（模型不可用或输出不合格）。错误状态：400输入不合格、401智能匹配未登录、403跨站请求、413内容过长、429请求过密。模型匹配每账号每分钟最多12次、单进程最多2路、8秒调用预算；浏览器12秒超时并保留输入。多人多实例部署仍需集中限流。

## 一、平台定位

本平台用于《微控制器原理及应用技术》的八项实验指导、按实验求助、教师复核和修订验证。八项实验的求助先由教师人工复核；模型辅助诊疗当前只覆盖以下三个专项：

- 定时器中断不触发；
- 串口通信乱码；
- 定时不准。

平台给出的内容是排查建议和练习任务，不替代教师判断、编译结果、示波器记录或实物运行结果。模型只生成教师初稿，学生只能看到教师批准的版本。

## 二、教师使用流程

### 1. 登录和建立班级

打开 `/teacher`，使用平台管理员创建的教师账号登录。

进入“班级设置”，点击“新建班级”：

1. 填写班级名称；
2. 选择“演示”或“课堂”；
3. 真实课堂填写学院要求的内容审查记录；
4. 保存后获得班级码。

“演示”数据只用于展示和联调，不计入课堂成效；“课堂”数据才允许作为真实教学记录，但必须先完成内容审查记录。

### 2. 发放匿名学习卡

在班级管理中生成学习卡。每张卡包含匿名学习编号和一次性恢复码。教师应将卡片分别交给学生，不能在公开投影中展示恢复码。

班级码只能用于加入课堂，不能代替教师登录。匿名编号、班级码和诊疗单号中的任何一个，均不能单独读取学生记录。

### 3. 配置实验

点击“配置实验”，逐项填写并确认：

- 实验名称和故障类型；
- 芯片型号；
- 晶振频率；
- 每次计数的时钟周期数；
- 定时器工作方式、目标时间或目标波特率；
- SMOD、时间口径和允许误差；
- 编译/测量工具与验证办法；
- 评分量规及每项满分。

定时目标当前按“单次溢出间隔”计算。若实验观察的是翻转输出的完整周期，教师应先换算成单次溢出间隔。参数未确认时，平台只允许定性排查，不输出数值初值和评分结论。

### 4. 审核学生诊疗

在“处理求助”中按班级、实验、状态或单号筛选。右侧审核区依次查看：

1. 学生原始提交；
2. 程序计算和知识图谱依据；
3. 模型初稿；
4. 教师检查点和补充练习；
5. 三级任务；
6. 分项评价。

教师可以保存复核稿、确认并发布，或退回补充。保存会形成新的复核版本；发布只发布当前版本。若页面提示版本冲突，应刷新后重新对照，不能覆盖其他教师已经保存的内容。

### 5. 维护八个实验的补充资料

进入“实验资料”，先选班级，再选实验一至实验八。填写资料名称、类别，选择 PDF、PNG、JPG、WebP、DOCX 或 PPTX 文件上传；单件不超过 8 MB。文件先保存为“未发布”，教师核对板卡型号、接线和实际适用条件后点击“发布”，本班学生才能在对应实验指导页查看。教师可改名、撤回或移除；撤回后学生不能从平台再次读取。不同班级的资料互相隔离，原文件及校验摘要随 SQLite 数据库备份。不要上传带姓名、学号的已填写报告。

八实验原始空白报告由平台单独保存供已登录师生下载；按实验整理的页面是操作导引，若两者表述不同，应先回原始报告和当次设备核实，再修改发布资料。

实验八已在演示班发布《普中-6 V1.2 电机接线依据（限对应板型）》节选；2401班的节选、原理图及备课《系统开发第4章》PPT均已上传为未发布资料。手册区分 ULN2003 驱动五线四相电机与 TC1508S 驱动四线双极型电机，不能把实验报告中混写的器件名称直接当作接线指令。任课教师确认当次开发板和电机后，再在“实验资料”发布适用文件。

### 6. 课堂中确认三级任务

学生完成基础任务后提交观察、代码和验证记录。教师在审核区确认记录是否满足量规：

- 仅“我已解决”不等于完成；
- 没有编译、测量或硬件运行证据时，不能标记为运行正确；
- “仍有困难”只生成求助事件，不会自动升级任务；
- 教师确认基础任务后，才开放综合任务；综合任务确认后才开放拓展任务。

### 7. 查看统计和导出

“课堂统计”按班级、实验和北京时间日期筛选。统计卡片会区分提交、待审核、求助、验证、有效参与编号和教师确认完成。

完成比例的口径是：

`教师确认完成的有效学习编号数 ÷ 有效参与学习编号数`

教师新确认参与人数后，统计会重新要求确认分母。没有测评依据时，平台不显示“掌握率”。案例导出包含实际发布版本、前后代码和验证记录；缺失的课堂效果或学生反馈会保留为空。

## 三、学生使用流程

### 1. 加入课堂

打开平台首页，填写教师发放的班级码、匿名学习编号和私密恢复码。进入后按原报告实验一至实验八的顺序了解课程，也可直接切换到课堂当前实验；手机上左右滑动实验标签，选中的实验会自动进入可见区域。每项实验先呈现原报告名称、目标、课程章节与报告任务，再依次查看“对应课程知识—实验准备—编写与运行—观察与验证”四步。点击“下载原始八实验报告”可核对原件；“故障专项诊疗”保留为教师另行配置的专题入口。切换或查看下一个实验不表示本实验已完成。班级码不能代替个人恢复码。

学生端的**8个实验指导**逐项对应原报告，课程章节提示按各实验的 PPT 整理；课件页所列**6件原理课件**是跨实验的补充专题，数量和任务不是一一对应。只在有关实验页出现相应课件入口。课件页也可展开“八个实验指导”目录，直接返回指定实验。实验一、实验六虽无专属交互课件，仍可查看其完整指导并向教师求助。

### 2. 提交现象和代码

学生先阅读当前实验指导；若仍有问题，点击“遇到问题，向教师求助”，写下真实观察即可。需要时展开自行排查，再选择“接线或器件”“代码或编译”“结果与预期不符”。选择方向不会替学生编造现象。代码区域默认收起，相关时再展开。支持的浏览器可点击“说出现象”将语音转成文字，识别结果仍须由学生核对，平台不会自动提交或保存录音。浏览器语音功能可能调用其服务商；不支持时直接键入。平台提醒删除姓名、学号、联系方式和代码署名；技术数字如 `11059200 Hz`、`50 ms` 和寄存器值会保留。

每个实验指导页提供报告任务、对应 PPT 知识提醒、接线与代码检查、所需观察和照片清单；下载核对单还可保留结果异常时的排查步骤。自查内容是课程资料整理的检查提示，不代替板卡实测或教师判断。实验一至八的求助先进入教师人工待办；平台按所选方向生成待复核检查点与三级任务草稿，教师核对实际条件、修改并发布后学生才可查看。现有模型诊疗只服务教师另外配置的“中断不触发、串口乱码、定时不准”三个专项，实验四的外部中断0不会被误判成定时器0中断。

各实验指导页配有对应的任务原理图，帮助区分观察对象与操作顺序。图示不是当前实验板接线图；涉及端口、驱动器和实物连接时，应以教师确认的板卡资料为准。

需要理解工作过程时，点击实验页的“原理课件”进入交互页。六件课件分别演示外部中断、定时器、串口帧、端口输出、数码管扫描及PWM占空比与步进相序核对要求；可逐步播放、重置，也可切换页面提供的参数观察变化。定时器和串口页展示按选定参数计算的结果；课件中的示意电平和器件图形不代表本班实物接线或运行验证。实验八的驱动匹配须先由教师核对。

定时课件以实验三为准：默认12 MHz、T0方式1、P0.0完整周期2 s。切换10/20/50 ms后，观察上方“每次翻转需累计”的次数和图中的溢出刻线；正确累计时2 s输出周期不变，属于应有结果。再切换“错误对照：每次溢出就翻转”，可看到输出周期错误地变成20/40/100 ms。拖动观察时刻或播放波形可查看累计进度与P0.0模型电平。70 ms是超范围反例，页面不绘制伪波形。此处没有执行学生的汇编程序，不是80C51指令级仿真；实验五的100 ms LED闪烁也不是此页的2 s方波任务。

教师可在“实验资料”上传本班板卡照片、示意图、说明书和空白报告，发布后供学生参考。学生求助当前仍只提交文字与代码，尚未提供学生作业图片上传；需要提交实物照片或短视频时，按教师指定的课堂渠道保留原件。不要把别的实验箱图片当本班实物证据。

提交后页面只显示单号和受理状态。待教师审核时，学生不能看到模型初稿、知识约束或未发布任务正文。

### 3. 执行已发布检查

教师发布后，学生按检查点顺序操作，勾选已执行的检查，并提交观察结果或修改后的代码。知识图谱、寄存器参考和代码定位默认折叠，需要时再展开。

### 4. 求助或申请验证

遇到困难时选择“仍有困难，需要教师帮助”；完成修改并有验证记录时选择“我已解决，申请教师验证”。教师确认前，页面保持当前任务级别。

### 5. 重新诊疗

若实验现象发生变化，可在原诊疗单上补充新一轮现象和代码。平台保留上一轮发布内容、学生回执和教师复核历史，不把旧答案直接带入新一轮。

## 四、课堂演示建议

建议用以下顺序进行现场演示：

1. 教师建立“演示”班级并配置一个已确认实验；
2. 展示匿名学习卡加入页面；
3. 学生提交“定时器中断不触发”和一段短代码；
4. 教师展示知识节点、真实依赖边和程序计算；
5. 修改一个检查点并保存；
6. 发布后切回学生页面，展示只有批准版本可见；
7. 学生提交“仍有困难”，展示任务不会自动升级；
8. 教师确认后再展示下一级任务和统计事件。

演示时应明确说明：演示记录、接口测试和模型样例不能作为真实课堂成效；真实课堂必须使用实际设备参数、实际参与人数和教师确认的验证记录。
