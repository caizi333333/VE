## 二、一次完整课堂闭环

六件课件分别在 `/courseware/interrupt`、`/courseware/timer`、`/courseware/serial`、`/courseware/port`、`/courseware/scan` 和 `/courseware/pwm`。定时课件只对应实验三的 T0/P0.0 任务：按报告给出的12 MHz与完整方波周期2 s，程序计算一次溢出的初值、溢出事件、累计次数和理论波形；10/20/50 ms 改变事件密度与累计次数，累计正确时完整周期仍为2 s。70 ms超出12 MHz、方式1的单次计数范围，页面拒绝生成波形。实验五的100 ms LED逐一闪烁与八位数码管扫描属于另一任务，不能直接套用实验三的方波模型。

这些页面是**限定条件下的教学时序模型**，不是指令级80C51内核仿真，也未加载学生汇编代码。端口极性、扫描时序和PWM波形是原理示意，不是现用实验板的接线图或运行证据。实验八同时写有四线双极型电机和ULN2003，驱动电路与当学期PPT版本仍【待核实】；因此PWM页暂不输出步进通电相序。最小补证为本班电机/驱动板型号、接线图和教师确认的控制程序，然后才能扩展相序模型。

## 三、平台状态和材料边界

| 状态 | 学生可见 | 可用于真实成效材料 |
|---|---|---|
| `pending_review` 待复核 | 单号、受理状态 | 只能作为过程记录，不能作为指导效果 |
| `manual_pending` 待教师处理 | 单号和人工处理提示 | 可记录模型故障及人工处置 |
| `released` 已发布 | 教师批准的检查点、任务和量规 | 可作为实际教学过程材料 |
| `rejected` 已退回 | 退回提示 | 只能说明需要补充，不能作为完成结果 |
| `test` 测试数据 | 测试账号和测试班级 | 不得写入课堂成效 |
| `demo` 演示数据 | 演示班级和示例任务 | 不得写入课堂成效 |
| `legacy_unknown` 历史待核实 | 教师端可回查 | 默认排除统计，待补来源后再决定 |
