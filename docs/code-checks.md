# 八实验求助中的代码依据

学生通过 `/api/lab-help` 提交现象和代码后，系统把课程核对单与代码候选检查一起保存为待教师复核稿。教师看到原始代码行号、命中行和复测建议；教师发布后，学生才收到审核过的检查步骤。此流程未调用模型，也不自动给分或判定实验完成。

## 当前覆盖

- 从直接写出的 8051 中断入口沿标签跳转跟踪到 `RET`，提示核对中断出口及连续触发结果。被 `ACALL` / `LCALL` 调用的普通子程序不作为中断出口跟踪，避免把其 `RET` 误报为中断返回错误。
- 仅对可识别的单条复位初始化路径、且结束于明确自循环的代码，检查显式关闭的相关控制位。实验四在有 INT0 入口时检查 EA / EX0；实验三、五、七在有 T0 中断入口时检查 EA / ET0；实验三有 T0 初值写入时检查 TR0。
- 支持直接的 `SETB` / `CLR` / `CPL`、IE / TCON 常量写入及有限位掩码操作。遇到未知寄存器值、子程序调用、条件分支等，不推断最终初始化状态。未在片段中出现某控制位，不等于没有初始化；查询式定时器不因缺少中断允许而报错。

每次最多提供三项代码候选检查，连同课程指引最多八个检查点。接线类求助优先列接线检查，代码及结果类优先列有依据的代码检查。检查步骤保留“若本段用于……”等条件，不把静态源代码路径写成实测结论。

## 边界与记录

检查不展开 C、宏、符号别名、包含文件或条件汇编；明确标记未支持的内容。注释与字符串不作为指令，重复标签或重复入口地址不猜测。无规则命中只代表本轮有限检查没有找到候选项，不代表程序正确。

这不是汇编器或控制流证明，不确认分支实际执行、栈平衡、时序、板卡极性、消抖或机械/声学效果。已有真实 AS31 / ucSim 运行入口可用于复测，实物结果仍须核对本班器材。候选检查不使用未确认的晶振或计数分频来推算数值。

分析版本、原始行依据和检查结果保存在本轮配置快照。学生同单修订时，上一轮检查点、练习、教师注意事项和配置快照一并归档；当前轮重新分析修改后的代码，旧候选项不会自动沿用。待审学生响应不包含这些教师复核材料。

规则依据：课程图谱及 [TEMIC C51 器件手册](https://www.keil.com/dd/docs/datashts/atmel/c51_hd.pdf) 的中断允许、入口和中断处理说明；普通返回指令参考 [Keil RET 文档](https://www.keil.com/support/man/docs/a51/a51_ret.htm)。手册说明不代替本班芯片与实验配置确认。
