## 2026-09-25 定时课件时序和视觉修订

针对“10/20 ms调整后画面不变”的反馈，重新对照原始实验报告实验三、实验五。实验三确实要求12 MHz、T0使P0.0输出完整周期2 s的方波；实验五的100 ms LED闪烁是另一任务。定时课件现将单次溢出事件、累计次数和P0.0波形分开显示：10/20/50 ms分别对应100/50/20次溢出后翻转，正确累计时理论完整周期均为2 s；错误对照的“每次溢出就翻转”分别产生20/40/100 ms周期。70 ms超出方式1单次计数范围，界面不绘制虚假波形。页面采用仪器面板式布局，保留参数、模式、波形、观察时刻和计算边界的清晰分区。

## 开源 8051 汇编与仿真内核替换验证（2026-09-25）

学生界面的汇编调试结果已改由 AS31 生成 Intel HEX，再由 SDCC ucSim/s51 执行机器码；原 TypeScript 内核不再提供界面读数。AS31 取上游固定提交 `53f1a78a1f262a67e1a388c20ec7e8357ac30eaa`，本机编译时修正 64 位系统位移常量；SDCC 版本 4.6.0_1，s51 版本 0.9.9。`npm run test:native` 的六项检查包含八段示例、六份历史源码实际汇编、HEX 校验、INT0 输入及实验三 10/20 ms 累计溢出差异，全部通过。实验三的 HEX 在 12 MHz 下执行 50 万条时 P0 为 FFH、累计约 1.000095 s，100 万条时 P0 为 FEH、累计约 2.000193 s；20 ms 初值若仍累计100次，此处不会同样翻转，改为累计50次才翻转。时间是仿真器执行机器码所得，不是示波器或实物记录。

浏览器操作了实验一编译与500条推进，实验三两次50万条推进和实验四 P3.2/INT0 输入；实验四 30H 与 P1 均从00H变为01H。实验八运行500条时由 s51 返回64个 P1 采样点，高、低电平都有出现，高电平样本20个（31.25%）；这仅说明控制程序形成了不同电平，不是电机端实测占空比。390px宽下调试器无页面级横向溢出。40个并发的本机编译加500条仿真任务完成40个、失败0个，P50 240ms、P95 281ms；这是工具链进程测试，不等于40个真实学生通过公网连续使用。八段程序仍为局部练习：实验五至八的完整外设现象与实物连接未由此验证。需要以教师确认的板卡、驱动与完整程序补齐外设模型，之后分别做实物对照。
