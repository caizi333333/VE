# 八实验汇编资料的来源与边界

`lab1`—`lab6` 是历史备课目录 `2025实验-丸子` 中相应源文件的文本转存，只统一字符编码、换行和行尾空格，并在文件头增加来源说明。**不是**本班已批准、已编译或已实物验证的最终程序；原文件仍留在备课目录。实验四候选源 `SHIYAN41.ASM` 使用外部中断 1（P3.3），与报告所要求的外部中断 0（P3.2）不一致，不能直接用于该实验。实验七有另一个虚拟仿真项目的候选源，尚未核实其时钟/显示/报警条件；实验八没有找到与报告指定电机和驱动组合匹配的汇编原件。

学生端的八个可编辑汇编程序位于 `src/lib/assembly-labs.ts`，均是短小教学摘录/生成示例，用于观察指令对寄存器、端口和中断的作用，不代替原实验报告完整程序。具体来源与缺失项见 `docs/project-deliverables-map.md`。
